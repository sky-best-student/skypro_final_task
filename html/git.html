Git

  • git init - создаёт новый локальный репозиторий Git в текущей папке
  • git status - показывает текущее состояние рабочей директории и индекс (изменённые, новые и подготовленные файлы)
  • git commit - фиксирует подготовленные изменения в истории репозитория с сообщением
  • git push - отправляет локальные коммиты в удалённый репозиторий
  • git pull - забирает изменения из удалённого репозитория и сливает их с текущей веткой
