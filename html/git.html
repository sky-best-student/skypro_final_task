Git

  • git init - Команда для созания нового репоизтория Git в пустой или существующей директории.
  • git clone "Url GitHub" - Команда для клонирования удаленного репозитория на локальный.
  • git status - Команда для проверки статуса файла в папке.
  • git add "название файла" - Команда для изменения статуса (отслеживания файла в гит).
  • git commit -m "Название коммита" - Команда для того чтобы показать Git, что файл изменен в локальном репозитории.
  • git push - Команда для внесения изменений c локального репозитория на удаленный.
  • git pull - Команда для внесения изменений c удаленного репозитория в локальный.
  • git branch "Навзание ветки" - Команда для создания ветки.
  • git checkout "Название ветки" - Команда для перехода c одной ветки на другую.
  • git commit -m "Название коммита" - Команда для того чтобы показать Git, что появилась новая ветка(и) в локальном репозитории.
  • git log - Комада для просмотров комитов в репозитории.
