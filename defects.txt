При выполнении работы найдены и исправлены следующие ошибки:

Файл index.html.
1. Лишний пробел в подвале страницы. Сейчас "202 4", а должно быть "2024".
2. В заголовке "Основныые интрументы" опечатка в слове Основные, лишняя буква Ы.
3. В заголовке "Основныые интрументы" опечатка в слове Инструменты, не хватает буквы С.
4. В "Тетирование WEB-приложений" опечатка в слове Тестирование, пропущена буква С.
5. Опечатка в слове "Windos" - пропущена буква W (Windows)

Файл cmd.html.
1. DATE и TIME необходимо поменять местами
2. MAKEDIR - такой команды нет, нужно указать MD
3. CD - это изменить каталог
4. DIR - это отображение файлов и папок в текущем каталог.
5. Не хватает кликабельной кнопки "Вернуться на главную"


Файл mac.html.
1. mkdir - правильно расшифровывается как "Make directory"
2. mv - правильно расшифровывается как "Move"
3. pwd - правильнее расшифровывать как Print working directory

Файл git.html
1. mv - есть опечатка в слове " расфшифровывается" лишняя буква ф
2. mv - не удаляет файлы
3. mv - в конце предложения вместо точки стоит "/"
4. Опечатка в кнопке "Вернуся на главную" в слове Вернуться не хватает ТЬ.
5. Кнопка "Вернуться на главную" срабатывала со второго раза( неверная команда) Вместо  href="mac.html" - необходимо href="../index.html
6. перед mv написать git.
7. Вместо команды ls - нужна git ls-files
8. Вместо pwd - нужна команда git status
9. Можно добавить команду git add.
